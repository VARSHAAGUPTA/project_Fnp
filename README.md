# FNP Sales Analysis Dashboard

## Overview

This project focuses on analyzing FNP (Ferns N Petals) sales data using Microsoft Excel to uncover business insights, customer purchasing behavior, and sales trends. An interactive dashboard was created to track key performance indicators and support data-driven decision-making.

## Objectives

* Analyze overall sales performance.
* Track revenue and order trends.
* Identify top-performing products and categories.
* Understand customer purchasing patterns.
* Generate actionable business insights through visualization.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning & Analysis

## Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Average Order Value
* Top-Selling Products
* Category-wise Sales
* Occasion-wise Sales Performance

## Key Insights

* Identified the highest revenue-generating products.
* Analyzed sales trends across different occasions and categories.
* Evaluated customer purchasing behavior.
* Highlighted top-performing products contributing to overall revenue.

## Dashboard Features

* Interactive Filters and Slicers
* Revenue Analysis
* Product Performance Tracking
* Occasion-wise Sales Analysis
* Dynamic Visualizations

## Project Outcome

The dashboard provides a clear view of business performance and helps stakeholders make informed decisions based on sales trends and customer insights.
